Política de privacidad · EstadisticasNBA Shorts

Última actualización: 22 de noviembre de 2026.

Qué hace la aplicación

EstadisticasNBA Shorts sube vídeos al canal de YouTube de su propietario (@EstadisticasNBA) mediante la API de datos de YouTube. Es de uso interno: solo la utiliza el propietario del canal.

Datos que usa

La aplicación solicita únicamente el permiso https://www.googleapis.com/auth/youtube.upload. Con él sube vídeos y sus títulos y descripciones. No lee, guarda ni procesa datos personales de ningún usuario de YouTube.

Almacenamiento y compartición

El token de acceso se guarda de forma privada en el entorno del propietario. No se vende, alquila ni comparte información con terceros.

Servicios de Google

Esta aplicación usa los Servicios de API de YouTube. Al usarla aceptas las Condiciones de servicio de YouTube. Consulta también la Política de privacidad de Google.

Revocar el acceso

Puedes retirar el acceso en cualquier momento desde la página de permisos de tu cuenta de Google.

Contacto

Para cualquier duda, escríbenos por mensaje directo a @EstadisticasNBA en Instagram.
